# bilibili-danmaku-overlay

B站直播弹幕桌面悬浮层：在看任何画面（比如全屏的电视直播、比赛直播）时，
把B站直播间的弹幕以"飘屏"形式叠在屏幕顶部。

- 弹幕层**全屏、置顶、背景透明、鼠标点击穿透**——不影响操作下面的任何窗口
- **画中画辅助**：B站直播窗口自动进入画中画并摆放至屏幕左下角（只有画面，
  弹幕走悬浮层），位置与大小可自行调整并记忆
- **双路音量控制**：B站直播和你日常浏览器（观看第二路直播）的音量分别调节，
  基于 Windows 系统音频接口，不抢焦点、不打断全屏
- 弹幕密度、滚动速度、字号、显示区域、粉丝牌等级门槛均可实时调节，设置自动记忆
- 弹幕过滤：本地屏蔽词文件（关键词 / 正则 / 屏蔽用户），保存后自动生效
- 控制条支持暂停（清屏）、退出，可折叠成屏幕边缘一个小箭头

> 仅支持 Windows 10/11。**仅供个人学习、研究与观看用途。**

## 工作方式

- **弹幕显示**：读取直播间公开展示的弹幕内容，在本机以悬浮层形式显示。
  不登录、不发送任何内容、不存储弹幕数据
- **窗口摆放**：辅助浏览器完成画中画等常规窗口操作；B站一侧使用独立的浏览器
  配置目录，与你的日常浏览器配置完全隔离
- **音量**：通过 Windows 系统音频接口按进程独立调节

本工具不下载、不录制、不转存任何音视频内容；不包含、也不请求任何账号凭证；
不修改、不干扰平台服务的正常运行。

## 环境要求

- Windows 10 / 11
- Python 3.10+（需含 tkinter，官方安装包默认包含）
- Microsoft Edge（画中画辅助使用）

## 安装

```bat
pip install -r requirements.txt
```

双击 `一键直播.bat`（或 `python 一键直播.py`），弹出单窗口双栏输入：

- B站直播间号或直播间网址（记住上次输入，回车即用）
- 第二路网页直播的地址（任意网页直播，会在你的默认浏览器打开，全屏自己按；留空则只看B站）

点关闭或取消则直接退出。想恢复桌面快捷方式：双击 `创建桌面快捷方式.bat`。

## 配置

所有设置保存在 `config.json`（首次运行自动生成，可参考 `config.example.json`）：

| 项 | 默认 | 说明 |
|---|---|---|
| font_size | 22 | 弹幕字号（控制条可实时调 12~44）|
| speed | 120 | 飘行速度（像素/秒，控制条可实时调）|
| density | 0.25 | 弹幕密度：只显示这个比例的弹幕 |
| min_medal | 0 | 粉丝牌等级门槛：只显示牌子等级≥N 的弹幕（0=不过滤，无牌=0 级，控制条可调 0~40）|
| top_ratio | 0.32 | 弹幕区高度占屏幕比例（控制条"区域"可实时调 10%~90%）|
| max_lanes | 8 | 最多几条跑道 |
| colored | false | 是否显示彩色弹幕（默认统一白色）|
| shadow | true | 黑色描边（亮画面上更清晰）|
| show_gift / show_guard / show_superchat / show_enter | — | 礼物/上舰/醒目留言/进场 显示开关 |
| pip_x / pip_y / pip_w / pip_h | -1 | 画中画小窗位置与大小；-1=自动（左下角 426×240）。手动拖动/缩放小窗后自动记住 |
| second_label | 网页 | 控制条上第二路音量的显示名称 |
| vol_bili / vol_cctv | 0.5 | 两路音量记忆 |
| block_words | [] | 本地屏蔽词（config 方式，包含即不显示）|
| 屏蔽词.txt | （文件） | **推荐的过滤方式**：同目录文本文件，一行一条规则；普通文字=包含即屏蔽，`re:表达式`=正则，`uid:数字`=屏蔽该用户；保存后约30秒自动热生效，无需重启 |

## 常见问题

- **弹幕一直是 0 条？** 该直播间可能未开放游客可见弹幕（主播设置），换个房间即可验证。
- **画中画没自动生效？** 页面加载慢时会自动重试最长 8 分钟；也可直接在B站播放器
  上手动点"画中画"。
- **想看彩色弹幕？** `colored` 改为 `true` 并重启。
